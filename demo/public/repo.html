README

reflex

buildpassingversion0.4.2licenseMIT

Calibrated reflexes for interfaces. reflex turns the small decisions an interface makes all day (which link to suggest next, which passage answers the question, which post to fold) into multiple-choice questions, and answers them fast enough to sit inside a click.

Overview

Most interface decisions are not open-ended. There is a state, a handful of typed options and a need to pick one quickly. reflex gives every option a probability, tells you which one wins and by how much, and abstains when the margin is too thin to act on.

  • Calibrated. Scores are temperature-scaled, so 0.8 means roughly eight times in ten.
  • Fast. Lexical ranking runs in well under a millisecond. The optional model backend has a hard timeout.
  • Honest. Every result says why: the matched terms, the margin and whether it abstained.
  • Small. No runtime dependencies. Works in browsers, Bun and Node.

Install

bun add @tacit-labs/reflex

Or with npm:

npm install @tacit-labs/reflex

Quick start

import { choose } from '@tacit-labs/reflex';

const result = choose({
  state: 'Searched "decision latency", opened an essay',
  options: [
    { id: 'latency', label: 'Latency: why 400 ms matters' },
    { id: 'ledger', label: 'The context ledger' },
    { id: 'mouse', label: 'A brief history of the mouse' },
  ],
});

result.best;     // 'latency'
result.p;        // 0.81
result.abstain;  // false

To run the bundled example from a clone:

git clone https://example.com/tacit-labs/reflex.git
cd reflex
bun install
bun run example

Usage

choose() is synchronous with the default lexical backend. Pass a model backend and it returns a promise instead; if the model does not answer within timeoutMs, reflex falls back to lexical ranking and marks the result.

import { choose, modelBackend } from '@tacit-labs/reflex';

const result = await choose({
  state,
  options,
  backend: modelBackend({ url: process.env.REFLEX_MODEL_URL }),
  timeoutMs: 250,
});

if (result.abstain) showChoices(result.ranked.slice(0, 3));
else act(result.best);

Every result carries the full ranking:

FieldTypeMeaning
beststringId of the top option.
pnumberCalibrated probability of the top option.
marginnumberLead of the top option over the runner-up.
abstainbooleanTrue when p or margin is below its threshold.
rankedRanked[]Every option with its score and reasons.

Configuration

The defaults suit link and passage ranking. Fit the temperature to your own traffic with reflex calibrate, which reads a log of past choices.

OptionDefaultDescription
threshold0.6Minimum probability to act without asking.
margin0.15Minimum lead over the runner-up.
temperature1.0Calibration temperature.
backend'lexical''lexical' or a model backend.
timeoutMs250Fall back to lexical ranking after this many milliseconds.
 
bunx reflex calibrate --log choices.jsonl --out reflex.config.json

Contributing

Issues and pull requests are welcome. Please open an issue before a large change so we can agree on its shape first. Run bun test before pushing; the calibration suite in test/calibration fails if expected calibration error rises above 0.05.
