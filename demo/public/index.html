A small web for testing a context harness.

Tacit reads the page you are on and how you got there, guesses what you are trying to do, and reshapes the page around it. These pages stand in for the places where that matters most: a search engine, an essay, a social feed and a code repository. Every page is static and served from this machine.

No extension? Run Tacit in these pages (off). New to it? How to use Tacit.

What Tacit notices

  • The search that brought you here
  • The words on the link you followed
  • What you select and copy
  • Where you slow down

What it does with it

  • Marks the passages that answer you
  • Offers jumps and next links, with confidence
  • Folds feed posts, with a reason
  • Hands a context packet to your agent
