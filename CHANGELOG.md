# Changelog

## 0.3.0 · unreleased

A context engine for every harness, and Jev at the center of the loop: decisions from any model you choose, or none at all, never slower than the page.

- **Any agent, not only Claude Code.** `bun run setup` finds Claude Code, Codex, Gemini CLI, OpenCode, Cursor and OpenClaw. After a yes, it gives each what suits it: a prompt hook, one line in its instructions about `tacit`, or the MCP tools. It keeps the first version of every file it changes as `<file>.before-tacit`, and leaves a settings file that is not plain JSON alone. [docs/agents.md](docs/agents.md) covers those agents and DeepSeek Harness, Cline, Windsurf, Zed, Goose and Aider, with every snippet. `bun run agents:check` runs each agent installed here once, against a stand-in model on this machine and a throwaway ledger. Claude Code 2.1.296, Codex 0.160.1, Gemini CLI 0.63.0 and OpenCode 1.18.35 each got the note for "what is this page about?" and none for "write a haiku about rain".
- **A note before the prompt, only when the prompt needs one.** Every way of handing context to an agent costs tokens, and a note in every prompt is the worst of them. A prompt hook (`tacit hook claude`, `codex`, `gemini`, `cline`, and a plugin for OpenCode) adds about 100 tokens on the screen only when the prompt builds on it. Words that point at the screen decide for free ("this page", 刚才看的). For anything else, while you have been browsing in the last half hour, Jev answers one yes or no within 2.5 s. Unsure, slow or stale, and there is no note. Measured with Jev through a proxy: three prompts that build on the page got the note (0.89 to 0.96), four that do not got none (0.04 to 0.32), each in about half a second. [docs/using-context.md](docs/using-context.md) has the costs and the reasoning.
- **`tacit`, on the command line.** The cheapest way in for any agent with a shell, and for people. `tacit` prints what is open in a few lines (about 110 tokens), and `--full` prints the packet. Also `intent`, `trail`, `search`, `page`, `brief`, `status` and `--json`. It opens the ledger read-only, so it works inside Codex's sandbox, which allows no writes to `~/.tacit` and no connections to `127.0.0.1`, and with the harness stopped. `bun link` puts it on PATH. `POST /v1/brief` gives other programs the hooks' answer.
- **The packet follows the person.** ⌥⇧C and `tacit now --full` now go the way your thought went:
  - what you are after, only when Tacit is sure enough (35%);
  - the path, oldest first;
  - what you did on this page, in order;
  - the page, read for its kind. A results page as its results, with the ones you opened marked. A feed as the posts about your goal. A short page whole. A long page as the passages that answer you, and its outline.
  Two people on the same page get different packets because they came by different paths.
- **DeepSeek decides too.** `bun run keys set deepseek`: DeepSeek's chat model, after any decision model you have a key for, reachable where OpenRouter needs a proxy. Thinking is off. An API with JSON mode but no JSON schema (`"json": "object"` in `models.json`) gets the schema in the request.
- **MCP for agents that load tools late.** Claude Code, Codex and Cursor show a server's instructions and tool names until a tool is needed, so the instructions now name the tools to reach for.
- **Who decides, your choice.** One key is enough: `bun run keys set openrouter` and Jev leads, Inception's decision model backs it, and a chat model gets a second look at the choices Jev is unsure of. A TypeSafe key works too. Any server that speaks TypeSafe's System One API or OpenAI's chat API, on this machine or not, goes in `~/.tacit/models.json`; Ollama, LM Studio, llama.cpp, vLLM and LiteLLM all do. [docs/models.md](docs/models.md) has the defaults, examples and measurements.
- **Kept on this machine, if you like.** `TACIT_PRIVACY=local` (or `"privacy": "local"`) asks only engines on this machine, such as `tev1` in Ollama, even with a cloud key set. Checked with every outbound request sent through a proxy that records and refuses: kept local, five questions and five real sites made no attempt to leave; not kept local, the same questions made 25. A `models.json` that cannot be used leaves only the code engine and says why: a typo cannot send decisions anywhere.
- **Never slower than the page.** Engines are hedged: a model still silent at 800 ms gets the next one alongside it, the first answer wins, and past 3.2 s the view on screen stays. The harness keeps a connection to each model host warm while you browse, because a new TLS handshake through a proxy took up to 6 s.
- **One confidence for every engine,** TypeSafe's definition, so thresholds mean the same with three options or twelve. A chat model's probabilities count for a little less. Through OpenRouter, every request asks for zero data retention.
- **`bun run models --try`** asks each engine five questions with clear answers and shows what it got right, how fast, and what it cost, and says so when a model does worse than the code engine. Measured: Jev 1.14 10/10 at 488 ms; the code engine 6/10; tev1 0.8B in Ollama 5/10 at 166 ms, which is why the local default is the 4B (not measured here). `bun run keys` keeps keys in a file only you can read and never shows them. A running harness picks up a new key or `models.json` by itself.
- **A token, and pairing.** The harness answers only clients that hold its token, and proves it holds the same token before a client sends it, so a program squatting on the port learns nothing. `bun run pair` hands the token to the browser through a local page.
- **For other harnesses.** `/v1/events` streams what happens in the ledger as server-sent events, with replay; `bun run events` prints it. `bun run setup` registers Tacit with OpenClaw too.
- **Always on.** `bun run service install` runs the harness from login on (launchd on macOS, systemd on Linux), carrying the shell's proxy settings, never a key or a password.
- **Search that scales.** Full-text search runs on SQLite FTS5 over everything kept, 20,000 visits now instead of 5,000.
- **Motion that says something changed.** The line grows into the slip instead of jumping; new words rise into place; the glyph fills like ink as Tacit goes from listening to suggesting to acting, and breathes once when the next step changes; the slip's rows come in one after another; marks on the page are drawn top to bottom. A render that changes nothing moves nothing, and none of it plays when the system asks for less motion.
- **Real sites.** `bun run live` runs the built extension on Wikipedia (English and Chinese), GitHub, MDN and Hacker News, with real models when a key is set.
- **Tried on the real web, and fixed.** A real session on Bing, a university's site, GitHub and LinkedIn showed what the demo site could not:
  - A link to the page you are on, or one the page marks as current, is never a next step any more; a link the page keeps for itself (a menu that opens instead) is followed by its address. Before, the line said it ran the step and nothing moved.
  - Search pages are read as their results, title and snippet each, on Bing, Google, Baidu and DuckDuckGo alike. A read that finds nothing (a redirect, a page still loading) never replaces what an earlier visit read, and a page with no body yet no longer stops the reader.
  - A search engine's click-through is no longer shown as a page you were on, and pages that ask for a password, such as sign-in and sign-up walls, are not read at all.
  - On a site, its own name tells nothing apart: on hkust.edu.hk, "hkust" no longer makes every link look relevant, while "erwin hkust" still finds Erwin.
  - After the computer sleeps, or the network changes, the harness drains the connections that died and sends requests on fresh ones, instead of timing out on each dead one until it is restarted.
  - Open, the slip numbers its rows and 1–3 alone picks one. Copying a short page for an agent no longer claims to be smaller than the page, and a passage read twice appears once in the packet.
- **Fixes.** When a model says nothing on the page fits, the line no longer offers the runner-up; it says what you are after. Section numbers and footnote marks (`4.1`, `[12]`) are never candidates. References, comments and "see also" in Chinese (参考文献, 评论) now rank low, as they always did in English: the pattern ended in an ASCII-only `\b`; and they are never jump targets. When every model fails, the extension keeps its own ranking instead of the harness's simpler one. The code engine reads the intent and the post the extension actually sends. A dropped connection is no longer reported as a timeout. Labels repeated beside every item ("edit", "编辑") are furniture, not next steps, and a page that is mostly links, like Hacker News, is read as its list of links.
- **Tests.** 224 unit tests, 45 end-to-end checks with pairing, 20 checks of the page runtime, 5 real sites, and every agent installed here against a stand-in model.

## 0.2.0 · 2026-10-21

What you read becomes context, X works for real, and Tacit learns from what you undo. And a guide, plus setup by pasting one line to your agent.

- **Reading attention.** A passage that holds the middle of the screen for 4 s of reading becomes context: it weighs the words you are after and leads the packet under "Passages I read closely". Turn on "Read with the pointer" in the popup and the passage your pointer rests on counts too, after a threshold you set (0.6–4 s). Skimming, idle time and hidden tabs never count.
- **X, for real.** Timelines that recycle posts keep every post you scroll past. Re-rendered posts get their folds back before they paint, and new posts are folded before they reach the screen. Opening a post is a new visit that remembers which post you came from. Conversations are never folded, and X messages and chats are never read.
- **Calibration.** Tacit raises its bar where you undo what it does, lowers it where you rarely do (0.5–0.8), and stops folding on sites where you keep opening folds. Opening any fold now counts. The dashboard's Learned view says what changed and why.
- **The dashboard** at 127.0.0.1:7766 becomes a context library: Now; Library, searchable in any language, by site or by what you read most; a page for every page, with what you read closely and how you got there; Trail; Learned; Connect, with the exact MCP command for your machine; and Privacy.
- **Deleting means everywhere.** Delete a page, or everything, in the dashboard, and the extension forgets it too; a stale copy can never bring it back. The harness remembers a deletion by a hash of the address, never the address.
- **English and 简体中文.** The line, the slip, the popup and the dashboard follow your browser's language, or the one you pick. Chinese intents are set upright, never in synthetic italics.
- **Calmer surfaces.** Confirmations ("Jumped to … · Undo") show in the line itself; the dark toast above it is gone. Once a step runs, the line moves on to the next one. Open, the line becomes the slip's header, your intent and where it came from, so nothing is said twice, and the slip is solid paper. When Tacit asks, it says "Looking for…" and offers three choices on ⌥1–3; picking a section takes you there in one step. ⌥⇧C has one name everywhere: Copy for agent. The dashboard sets times and counts in the sans with tabular figures and drops the confidence bar.
- **Natural Chinese.** 上下文 instead of "context" in the interface, 用鼠标跟着读 for pointer reading, and 停在屏幕上 where the old wording suggested eye tracking.
- **Try it with nothing installed.** The demo site's `/try` runs Tacit as a page script, the same code as the extension, with storage in the page; `/x/home` is a timeline that recycles posts the way X does.
- **How to use Tacit.** [GUIDE.md](GUIDE.md), also in 简体中文: try it in a minute, what to do and what you will see, keys, models and keys, privacy, what to do when something is off, and a few lines to send someone. The popup, the dashboard and the demo link to it.
- **Set up with one paste.** Give a coding agent one line and it follows [docs/agent-setup.md](docs/agent-setup.md), asking only where a person is needed. `bun run setup` does the deterministic part: builds, checks the harness and where its ledger is, and, after a yes, connects Claude Code for every project and installs a Tacit skill that tells it when to use the tools.
- **Who decides.** DESIGN.md maps every decision in the loop to one owner (code, pre-written, a small typed model, or your own agent) with its time budget and its fallback.
- **[DESIGN.md](DESIGN.md):** the north star (less input), the principles, the loop, every signal and its weight, and when Tacit borrows from other tools.
- **Fewer permissions.** No `tabs` permission, and host access narrowed from `<all_urls>` to `http` and `https`.
- **The store kit, for 0.2.0.** `docs/store` justifies only the permissions the extension now asks for, describes the new data (passages read closely, X messages left out, deletion), and has a 简体中文 listing ready, since the package ships `_locales/zh_CN`. Images, the demo video and the README GIF re-rendered from the new build; `bun run record` now makes the GIF too.
- **Jumps land like anchor links:** the target near the top, the answer below it in the reading band, instead of centered under the previous section.
- **Fixes.** Clicking a fold no longer counts as interest in the posts it hides. Unfolding opens the whole run, even where the page recycled part of it. The popup hides the site switch on browser pages. The Learned view no longer says Tacit acts on its own: it offers, one key away. Reading a passage weighs its words but no longer renames your goal after a sentence you copied from it. A 40% undo rate moves the bar one step, not two (float rounding). The setup command adds Tacit to Claude Code for every project (`--scope user`), not only the tacit folder.
- **Tests.** 140 unit tests. The extension's end-to-end run grows to 41 checks (reading, pointer reading, Chinese, every dashboard view, a deletion reaching the extension), and `bun run e2e:web` checks the page runtime against an X-style virtual timeline (20 checks). Browser tests ignore any system proxy, so they run where one is set.

## 0.1.1 · 2026-10-21

Ready for the Chrome Web Store, and plain about what happens to your data.

- **Privacy policy.** [PRIVACY.md](PRIVACY.md) lists everything Tacit reads, where it goes, exactly what reaches Jev and how to delete it. The README links to it.
- **Chrome Web Store kit** in `docs/store`: listing copy in English and 简体中文, permission and data-use justifications, five screenshots, the promo tile and the store icon, re-rendered with `bun run store`.
- **"Local by default."** The extension and the popup no longer say everything stays on your machine, because Jev, when you turn it on, sends decision requests to TypeSafe. The README now describes those requests precisely: next-step labels with short snippets, or up to 40 feed posts.
- Playwright 1.64.1 and actions/checkout 7.

## 0.1.0 · 2026-10-18

First public release.

- **Extension** (Chrome MV3): reads the page and how you got there, and draws one line at the bottom of every page. Jump to the answer, focus, fold a feed around your intent, copy the command you came for, and hand the page to your agent with ⌥⇧C. When unsure, it asks with choices.
- **Intent**: inferred from searches, selections, copies, clicks and dwell, with evidence and a calibrated confidence. Anything you state outranks inference.
- **Decisions**: a local engine offline; TypeSafe's Jev with a key, falling back to local on any error or timeout.
- **Harness**: a SQLite ledger in `~/.tacit`, an HTTP API on 127.0.0.1:7766, search over everything read (English and Chinese), and a ledger UI.
- **MCP server** with five tools: `tacit_current_context`, `tacit_intent`, `tacit_trail`, `tacit_search`, `tacit_page`.
- An offline demo site, 90 unit tests and a 30-step end-to-end run in real Chromium.
